# LRWeb Console: practice mockup

Double-click `lrweb-console-mockup.html` to open it. It works offline, with no install and no server.
Everything in it is pretend: nothing touches a real server, client or message.
After changing the real code, rebuild it with `npm run mockup`.

Things to try, in order:
1. Start here: the seven missions tick off by themselves as you use the pages.
2. Traffic lab: press "Pretend down" on the three main servers, then "Send 10 visits". Watch spare-01 take them.
3. Traffic lab: choose a server under "Move visitors to", pick "Gradually", and press "Start the move".
4. Secure chat: create the vault with the practice passphrase, send a message, then press "Ralph replies".
5. Secure chat: run each attack in the Attack lab and read what the real checks decide.
6. Move a website: press "Start the practice move", then the switch button. Every step is labelled Simulated.
