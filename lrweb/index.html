    Rule 01

    Plain English, always

    If we can’t explain something without jargon, we don’t understand it well enough. You’ll never get an email from us you need to Google.

    Few clients, done well

    We cap our client list deliberately. When we’re full, we say so and start a waiting list. Quality doesn’t survive a hundred clients.

    If you don’t need something, we’ll tell you. The plan you’re on should be the cheapest one that genuinely does the job.
